## PHASE 1

### Production Core — Backend + Website + Booking Engines

**Timeline:** Month 1 (1 July 2026 → 31 July 2026)
**Payment:** ₹25,000

> First production build. **Website only — no app, not live.** This is the foundation every category reuses. The core work is the **booking engine** for each service.

**What we need delivered (on staging — not public):**

- Production Backend
- Database Design (SQL)
- REST APIs
- Website (Customer web + Partner web + Admin Panel) — *web only, no native apps*
- **Booking Engine** for each of the 7 service groups below

**NOT in this phase (deferred to Phase 2):**

- ❌ Razorpay payment integration
- ❌ MSG91 OTP integration
- ❌ AI Chatbot / AI Search
- ❌ Public/live deployment
- ❌ Mobile apps

**Fixed-price service categories (booking engine — web build):**

- 🔧 Technician Services
- 💄 Beautician Services
- 🏠 Home Services
- 🐾 Pet Services

**Workforce & project service categories (booking engine — web build):**

- 👷 **Construction Labour** — crew / lead-settlement model
- 🧰 **Man Power & Support Staff** — bulk/temp staffing
- 🎥 **Event & Media** — enquiry → quote → milestone pay

*Includes the quote/estimation flows: Smart Inspection Booking · Digital Estimation Engine · Vendor Quote System · Additional Work Approval · Customer Feedback · Vendor Dashboard · Warranty System (built, not activated).*

## CHANGE REQUEST (CR)

Only **Major Changes** after approved scope are CRs (New Categories, Modules, Workflows, Third-Party Integrations, New Payment Methods, Major UI/UX Redesign, AI Expansion, Architecture Changes, New Reports/Dashboards). **Minor Changes** (bug fixes, alignment, button position, text/color/font, minor validation/usability) are not CRs. Major CRs require mutual written approval for cost and timeline.
